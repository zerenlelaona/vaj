# VAJ — Visa-Aware Jobs NL 🇳🇱

**Live: https://zerenlelaona.github.io/vaj/**

For internationals job-hunting in the Netherlands: check whether a company is an
**IND recognised sponsor** (i.e. can sponsor a Highly Skilled Migrant permit),
browse ~280 employers known for hiring internationals, and track applications
and interview prep — all in the browser, no account, no server.

Data source: the official
[IND public register of recognised sponsors](https://ind.nl/en/public-register-recognised-sponsors)
(Regular labour & highly skilled migrants), which the IND republishes monthly.

## Pages

- **Check** — paste a company name, get a verdict: ✅ recognised /
  🤔 possible match / ❌ not in the register. Fuzzy matching handles legal
  suffixes, so "adyen" finds *Adyen N.V.* and "booking.com" finds
  *Booking.com B.V.*
- **Discover** — pick an industry, narrow by job function, get companies with
  direct careers links. Every sponsor badge is resolved against the real
  register at build time, never asserted by hand.
- **Sponsors** — the full register (12,000+ organisations), searchable by name
  or KvK number.
- **Tracker** — saved roles with status, permit fit and notes; inline editing;
  Backup / Import.
- **Prep** — per-role interview prep: research notes, likely questions, a STAR
  story lineup, post-interview debrief, and "Export prep pack" (markdown).
- **Stories** — a reusable STAR story bank tagged by competency.

## How it works

Static site, no backend:

- **Your data** (tracked roles, stories, prep notes) lives in your browser's
  `localStorage`. It is never uploaded and never in this repo. Use
  **Backup** on the Tracker page to save a file — that's also how you move data
  to another browser or device.
- **The register** ships as `public/sponsors.json`, generated by
  `scripts/build-data.mjs`.
- **Refreshing** happens in CI, not in the app: browsers can't fetch `ind.nl`
  (CORS), so
  [`refresh-register.yml`](.github/workflows/refresh-register.yml) re-scrapes
  monthly, commits only if something changed, and redeploys.
- **Offline**: a service worker caches the app and the register, so it keeps
  working with no internet and can be installed to a phone home screen.

## Develop

```bash
npm install
npm run dev          # http://localhost:3000
npm run data         # re-fetch the IND register + re-resolve companies
npm run build        # static export to out/
```

Set `NEXT_PUBLIC_BASE_PATH=/vaj` when building for GitHub Pages (CI does this).

Stack: Next.js (App Router, static export) · TypeScript · Tailwind CSS ·
cheerio (build-time scraping only).
